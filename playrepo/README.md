# PlayRepo Test Add-on

Public test repository for the Nuvio PlayRepo add-on.

Manifest URL:

`https://raw.githubusercontent.com/qera18/playrepo-test/main/playrepo/manifest.json`

The seed catalog and stream files start empty. Install the matching PlayRepo test APK, enter a GitHub Personal Access Token that has Contents read/write access to `qera18/playrepo-test`, then run a scan to populate `data/catalog.json`, `data/streams.json`, and the static category files. Never commit or share the token.
