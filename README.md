# PlayRepo test repository

Public Nuvio add-on test repository owned by qera18.

Manifest URL: https://raw.githubusercontent.com/qera18/playrepo-test/main/playrepo/manifest.json

The initial catalog and stream data are intentionally empty. Install the matching PlayRepo test APK, set a GitHub PAT with Contents read/write access limited to this repository, then run a scan to populate `data/catalog.json`, `data/streams.json`, category catalogs, metadata, and stream files. Never commit or share the PAT.
